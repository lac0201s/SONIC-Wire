## 3. Optimisation decisions

1. **Fonts**: variable, self-hosted, `font-display: swap` via `@fontsource`, only the
   axes used (weight); no italic files beyond what is rendered.
2. **Icons**: imported per-name from `lucide-react` so Rollup tree-shakes the rest;
   the built app chunk is 256.8 kB (80.5 kB gzip) including React.
3. **Canvas**: DPR capped at 2, particle count 46, filament count 7 per density unit,
   RAF stopped when offscreen or unmounted, single static repaint under reduced
   motion.
4. **Thumbnails**: generated server-side at 640 px wide, JPEG quality tuned by FFmpeg
   `-q:v 4`, served with `Cache-Control: private, max-age=86400` and an ETag.
5. **Code splitting**: every route is a lazy chunk (27 chunks total); the marketing
   landing and the console do not share route code.
6. **No web fonts from third parties**: eliminates a third-party request and a
   privacy disclosure.
